# 前端回归测试固化（2026-11-04）

## 背景

此前每次改前端（`web/*.html/*.js`）都是一次性 headless 脚本验证，脚本随任务清理，
没有沉淀成仓库里的常驻回归。本次把验证固化到 `tools/web-test/`，改页面前先跑一遍。

## 方案

- 技术栈：**puppeteer-core + 本机 Chromium**（`.20` 的 `~/.cache/ms-playwright/chromium-1248`，
  自动发现，可用 `CHROME_PATH` 覆盖），实机访问板子页面（默认 `http://192.168.1.50`，`BASE_URL` 可覆盖）。
- 结构：
  ```
  tools/web-test/
  ├── run.sh                 # 入口：检查 node / 装依赖 / 跑 runner
  ├── runner.js              # 收集 tests/*.test.js，汇总断言
  ├── lib/harness.js         # 浏览器发现、断言汇总、页面加载、可达性探测、画列计数
  ├── tests/chat-page.test.js    # 主聊天页回归
  ├── tests/mem-page.test.js     # 内存监控页回归
  └── README.md              # 用法与覆盖说明
  ```
- 板子不在线时默认**跳过**并返回 0（`SKIP_IF_DOWN=0` 时按失败处理）。

## 覆盖点（48 条断言）

**index.html 主聊天页**：无 JS 异常；输入框/发送/设置按钮/侧栏存在；设置面板打开关闭；
语言下拉即时生效（中文/英文 + localStorage 持久化）；主题下拉暗色/浅色（`data-theme` +
localStorage，背景色确实变化）。

**mem.html 内存监控页**：无 JS 异常；标题/按钮行（只有实时/回放，无旧重放按钮）；
主图已绘制（像素级）；实时列数 >0 且随时间增长；状态行单行省略（nowrap + ellipsis）+
超长文本不撑高（防抖回归）；按钮行与图表 16px 间距；数值面板总 DRAM 335,881 (100.0%) 且
其余各项含百分比；设置面板语言切换即时生效、刷新保持、切回英文；**实时/回放切换竞态**
（点回放后状态不闪回实时文案）；回放流程（有数据播放完成且表格有数据，无数据时走空态）。

## 验证

在 `.20` 上执行 `node runner.js`（板子在线）：**断言 48 条，失败 0 条，跳过 0 条**。

## 已知限制

- 实机测试依赖板子在线；没有 mock 模式（如需离线跑可后续加）。
- 语言默认值取决于浏览器语言（headless Chromium 为 en），断言按实际语言分支判断。
- 测试会触发页面 `/api/mem` 轮询（0.5s 一次），但不发送真实聊天请求。
- 设置面板遮罩会挡住页面按钮点击——测试流程里先关闭面板再点实时/回放（也是用户实际操作顺序）。
