# 代码块下载扩展名修复记录（2026-11-04）

> 现象：安卓端下载代码块时，文件名带 `.txt` 后缀（预期按语言给扩展名，如 `.py`、`.java`）。

## 一、查证

- Firefox 桌面版下载名正确：`code-<时间戳>.py`；
- 问题出在两处可能：
  1. 下载用的 Blob MIME 是 `text/plain`，部分移动端下载管理器会按 MIME 把扩展名"修正"为 `.txt`；
  2. 代码块语言未在映射表里（或没有语言标记）时，按设计会兜底为 `.txt`。

## 二、修复

1. **Blob MIME**：`text/plain;charset=utf-8` → `application/octet-stream`
   （下载为"任意文件"，下载管理器不再按 text/plain 修正扩展名）；
2. **扩充语言映射** `LANG_EXT`：在原有（python/js/ts/c/cpp/html/css/json/bash/go/rust/java/kotlin/sql/md 等）基础上，
   补充 php / ruby / lua / swift / dart / scala / r / perl / haskell / elixir / erlang / clojure / ocaml /
   fortran / asm / proto / graphql / diff / patch / dockerfile / makefile / cmake / nginx / vue / svelte /
   jsx / tsx / powershell / bat / toml / ini / scss / less 等 40+ 语言；
3. 无语言标记的代码块仍兜底 `.txt`（保持原行为）。

## 三、验证（Playwright Firefox）

同一页面渲染 python / java / 无语言三个代码块，分别下载：

| 代码块 | 下载文件名 |
|---|---|
| python | `code-xxx.py` |
| java | `code-xxx.java` |
| 无语言 | `code-xxx.txt`（预期） |

## 四、说明

安卓 Firefox 的下载管理器行为无法在本机直接复现；MIME 改为 octet-stream 是针对
"下载管理器按 MIME 修正扩展名"的常见规避手段，请在外网手机上再实测一次。
