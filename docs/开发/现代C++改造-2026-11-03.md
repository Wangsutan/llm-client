# 现代 C++ 改造记录（2026-11-03）

> 起因：用户要求评估项目里可用现代 C++ 的地方（智能指针、类、模块等）。先做了全项目
> 复核，结论：ESP32 core 3.3.12 实际用 **C++20（gnu++2a）**，语言特性大多可用；但嵌入式
> 场景下很多"现代"改法只增开销。经用户批准，实施 6 项，未实施项与理由见下。

## 一、前提事实

- 编译标准：`esp32-libs/3.3.12/flags/cpp_flags` 里是 `-std=gnu++2b` 后被 `-std=gnu++2a`
  覆盖，即 **C++20**；`-fexceptions` 开（项目代码不用异常）、`-fno-rtti` 关 RTTI。
- 优化 `-Os`。ESP32 320KB 堆、loopTask 8KB 栈，项目刻意静态分配。

## 二、实施的 6 项

| # | 项目 | 位置 | 内容 |
|---|---|---|---|
| 1 | 常量 → `constexpr` | `llm_limits.h` | `LLM_ANSWER_MAX` / `LLM_KEEP_MAX` / `WORK_BUF_SIZE` 由 `#define` 改为 `constexpr size_t` |
| 2 | `enum` → `enum class` | `http_response.h` | `StreamEnd` 类型化，函数内用 `using enum StreamEnd` 保持简短 |
| 3 | RAII 守卫 | `llm_http.cpp` | 新增 `ClientGuard`（析构 `stop()`），删除 `streamImpl` 里 4 处分散的 `client.stop()` |
| 4 | 指定初始化器 | `llm_http.cpp` | `kOllamaSpec` / `kOpenaiSpec` 改为 `.name = ...` 形式，防字段错位 |
| 5 | 类封装 | `payload.h/.cpp` | 自由函数 + 文件级 static 状态 → `PayloadReceiver` 类；`web_chat.cpp` 持有实例 |
| 6 | `[[nodiscard]]` | `llm_http.h` / `llm_client.h` | `backendStream()` / `llmStream()` 返回值不可忽略 |

## 三、PayloadReceiver 类封装细节

- 接口：`uploading(WebServer&)` / `read(WebServer&, JsonDocument&)` / `release()`；
- 每轮状态（`workLen_`、`workReady_`、`uploadBody_`、`gzipUpload_`、`reject_`、`uploadCap_`）
  收为成员；
- 工作区 `s_work` 改为**类静态成员**（仍在 `.bss`，48KB 地址固定，不会进栈）；
  `tinfl_decompressor` 仍留在 cpp 文件级 static（避免 miniz.h 进头文件）；
- 实例在 `web_chat.cpp` 定义：`static PayloadReceiver s_payload;`，不改变路由注册方式。

## 四、明确未做的（复核结论）

| 项 | 理由 |
|---|---|
| 智能指针（`unique_ptr`/`shared_ptr`） | 项目刻意静态分配以避免堆碎片；自动释放用轻量 RAII 守卫即可，智能指针是负优化 |
| C++20 modules | 标准够，但 arduino-cli 构建系统不支持 |
| `std::string_view` / `std::optional` / `std::variant` | 与 Arduino `String` / ArduinoJson 的返回值模式不匹配，收益低 |
| 结构化绑定 | 会复制 `String`，且 `ep.host` 等直接访问更直观 |
| C 风格转换全改 `static_cast` | 纯风格，diff 噪音大，不改行为 |
| 异常重构 | 编译器开了 `-fexceptions`，但嵌入式 catch 成本高，保持返回值风格 |
| 类化 console_ui / memprobe / wifi_manager | 单实例、无状态或少状态，类化收益低 |

## 五、验证

- **编译**：`arduino-cli compile`（esp32 core 3.3.12，default 分区）通过；
  固件 1,133,472 → 1,133,488 B（+16 B）；Global variables 109,760 B 不变。
  中间各步（constexpr / enum class / RAII / nodiscard / PayloadReceiver）均单独编译通过。
- **格式化**：`clang-format --dry-run` 全部 0 差异。
- **烧录回归**（板子 IP `192.168.1.50`，`.21` 串口抓 IP + curl，10/10 通过）：
  静态页、marked.min.js、config、models、chat（gzip/明文）、summarize、空 message 400、
  坏 JSON 400，串口日志 `[http] stream end: normal`。

## 六、已知观测差异

RAII 守卫让 `client.stop()` 从显式调用改为作用域析构：串口日志里
`memSample("upstream_closed")` 现在出现在 `stop()` **之前**（原实现是 stop 之后），
内存打点数值可能有几十字节的微差；仅影响探针日志顺序，不影响功能与协议。
