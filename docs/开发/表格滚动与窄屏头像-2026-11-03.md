# 表格横向滚动与窄屏头像隐藏记录（2026-11-03）

> 需求：窄屏下 Markdown 表格太挤，要能左右滑动且每列有最小宽度；窄屏下不显示头像。

## 一、实现

1. **表格横向滚动**：`renderMarkdown()` 渲染后调用新增的 `decorateTables()`，把每个
   `table` 包进 `<div class="table-wrap">`；CSS：
   - `.table-wrap { margin: 8px 0; overflow-x: auto; -webkit-overflow-scrolling: touch; }`
   - `.table-wrap table { margin: 0; border-collapse: collapse; min-width: 100%; }`
2. **每列最小宽度**：`.bot .msg th, .bot .msg td { min-width: 80px; word-break: break-word; }`
   ——列内容窄时按 80px 保底，长文本自动换行；列多/内容宽时由外层容器横向滚动。
3. **窄屏隐藏头像**：`@media (max-width: 640px) { .avatar { display: none; } }`。

## 二、验证（headless Chromium）

| 场景 | 结果 |
|---|---|
| 窄屏 400px | `.table-wrap` 存在；表格宽 401 > 容器 273（**可左右滑动**）；表头列宽 80px（最小宽度生效）；**头像 `display:none`** |
| 宽屏 1200px | `.table-wrap` 存在但不滚动（表格 593 = 容器 593，`min-width:100%` 撑满）；头像正常显示（`display:flex`） |

## 三、建议（未实施，供决定）

- 窄屏隐藏头像后，消息列宽可从 `max-width: 78%` 放宽到 ~90%（更利用空间）；
- 表格滚动可加"边缘阴影/滚动条提示"，提示用户可左右滑动；
- 表格行多时可让表头 `position: sticky` 固定（非必须）；
- 窄屏下消息/代码块的内边距可略调大，提升触摸可读性。

## 四、追加优化（2026-11-03 晚）

用户确认追加三项（均纯 CSS）：

1. **窄屏消息宽度放宽**：`@media (max-width: 640px) { .msg-wrap { max-width: 90%; } }`
   （放在 `.msg-wrap` base 规则之后才能覆盖——之前放在前部被 78% 覆盖，已验证）；
2. **表格滚动边缘阴影**：`.table-wrap` 左右两侧各 18px 渐变阴影 + 表格白底
   （不溢出时白底覆盖阴影、无视觉影响；溢出滚动时两侧阴影提示可滑动）；
3. **窄屏消息内边距**：`.msg { padding: 8px 12px; }`（原 6px 10px）。

验证（headless，400px 宽，长消息 + 5 列表格）：
`.msg-wrap` max-width=90%、消息宽约 85% 视口；表格可滚动（scrollWidth > clientWidth）且阴影存在。
