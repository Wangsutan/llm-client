# 代码块语法高亮记录（2026-11-04）

> 需求：Markdown 代码块做语法高亮（染色）。

## 一、方案

- 引入 **highlight.js 11.11.1**（BSD-3），本地打包进 LittleFS（不依赖 CDN，离线/外网都可用）；
- 主题用 **github-dark**（代码块保持深色底，浅色/深色两套主题下观感统一）；
- 只在有语言标记（`language-xxx`）的代码块上高亮，无标记的代码块跳过（避免 auto-detect 开销）。

## 二、实现

| 文件 | 改动 |
|---|---|
| `web/highlight.min.js`（新增） | highlight.js v11.11.1，127 KB |
| `web/index.html` | `marked.min.js` 之后引入 `/highlight.min.js` |
| `web/style.css` | 末尾并入 github-dark 主题 CSS + 覆盖 `.code-block pre code.hljs` 的 padding/background（保持原有代码块样式） |
| `web/app.js` | `decorateCodeBlocks()` 里对含 `language-` 的 code 调用 `hljs.highlightElement(code)`（复制/下载读 `textContent`，不受高亮影响） |
| `web_static.cpp` | 新增 `handleHighlight()`（`/highlight.min.js`） |
| `web_server.cpp` | 注册 `/highlight.min.js` 路由 |
| `web_internal.h` | 声明 `handleHighlight()` |

LittleFS 内容增加约 128 KB（网页文件总量约 200 KB，spiffs 分区 1.4 MB，余量充足）。

## 三、验证（headless Chromium）

- 含 python 代码块的 AI 消息：`code.hljs` 类存在，7 个高亮 span、6 个上色
  （`def` 红、`hello` 紫、`print` 橙、字符串蓝、`return` 红 —— github-dark 配色）；
- 代码块复制按钮正常，点击复制 toast「Code copied」，复制内容仍是原始代码文本；
- 无失败请求、无 console/page 错误。

## 四、未动

- 代码块深色底（两套主题通用），未做随主题明暗切换的高亮配色。
