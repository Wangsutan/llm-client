## 二、复制按钮（参考 llm-web）

- 位置：**AI 消息与用户消息**气泡下方的操作栏，悬停整条消息时浮现（触屏设备常显）；
  AI 消息复制 Markdown 源，用户消息复制用户原话；
- 内容：AI 消息复制 **Markdown 源数据**（`dataset.raw`，未渲染原文），而不是渲染后的 HTML；
- 数据来源：
  - `add('bot', text)` / `add('me', text)` 直接创建时写入 `dataset.raw`；
  - `renderMarkdown()` 渲染时写入 `dataset.raw`（历史加载也覆盖）；
  - 流式输出时每帧同步 `botMsg.dataset.raw = full`；
- 交互：点击后按钮短暂变「已复制」+ 底部 toast「已复制」；空内容提示「没有可复制的内容」；
- 剪贴板：`navigator.clipboard`（HTTPS/安全上下文优先）+ `document.execCommand('copy')` 降级（板子走 http，实际用降级路径，已实测）。

## 五、Markdown 代码块复制 / 下载（2026-11-03 追加）

- 实现：`renderMarkdown()` 渲染完成后调用 `decorateCodeBlocks()`，把每个 `pre > code`
  包装成 `.code-block`（`.code-head` 内为语言标签 + 「复制」+ 「下载」两个按钮）；
- 复制：`copyToClipboard(code.textContent)`（复用现有剪贴板函数），按钮短暂变「已复制」+ toast「已复制代码」；
- 下载：`new Blob([code.textContent])` + `<a download="code-<时间戳>.<扩展名>">` 触发；
  扩展名按 `language-xxx` 映射（python→py、js→js、cpp→cpp、sh→sh、md→md 等，未知→txt）；
- 只在渲染后的 DOM 上后处理（不依赖 marked renderer API），`sanitize()` 清理不影响按钮（用 addEventListener 绑定）；
- 行内 `code` 不受影响（仅处理 `pre > code`）。

验证（后续 headless）：含 python 代码块的 AI 消息 → `.code-block`、`.code-lang=python`、
复制按钮出现且点击后 toast「已复制代码」、下载按钮点击后 toast「已开始下载 code.py」。
