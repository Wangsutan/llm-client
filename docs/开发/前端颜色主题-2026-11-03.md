# 前端颜色主题记录（2026-11-03）

> 需求：前端可以切换颜色主题（浅色 / 深色）。设置项放在设置弹窗内（「主题」下拉）。

## 一、实现

1. **CSS 变量化**：`style.css` 顶部定义 `:root`（浅色）与 `[data-theme='dark']`（深色）
   两套语义变量（约 28 个）：背景/面板/悬停/边框/文字三档/强调色/用户气泡/错误气泡/
   头像底/代码块/内联代码/成功色/阴影/表格滚动阴影。所有硬编码颜色替换为变量引用。
2. **文字颜色**：`body { color: var(--text); }`（深色主题需要浅色文字）。
3. **主题状态**：`localStorage('esp32-chat-theme')` 持久化，默认 `light`；
   `applyTheme()` 把主题写到 `document.documentElement.dataset.theme`，启动时应用。
4. **设置面板**：新增「主题」下拉（浅色/深色），位置在「语言」之后、「后端」之前；
   change 时立即生效并保存。
5. **i18n**：新增 `theme` / `themeLight` / `themeDark` 三个键（中英文已有）。

## 二、验证（headless Chromium）

| 场景 | 结果 |
|---|---|
| 初始（light） | `data-theme=light`；body 背景 `rgb(245,245,245)`、文字 `rgb(15,23,42)`；侧栏/主面板浅色 |
| 设置顺序 | 语言 → **主题** → 后端（`compareDocumentPosition` 验证）；英文界面下标签为 `Theme` |
| 切 dark | `data-theme=dark`；body 背景 `rgb(15,23,42)`、文字 `rgb(226,232,240)`；侧栏/主面板/气泡深色 |
| 刷新持久化 | 刷新后仍为 dark，localStorage 保存 `dark` |
| 切回 light | 恢复浅色，localStorage 保存 `light` |

## 三、亮色主题下的配色方案（2026-11-03 追加）

- 设置弹窗在「主题」之后新增「配色」下拉，共 5 套（仅影响亮色主题）：
  经典蓝（默认）/ 护眼绿 / 静谧紫 / 暖橙 / 青碧；
- CSS：`[data-theme='light'][data-palette='xxx']` 覆盖变量
  `--accent` / `--accent-hover` / `--accent-strong` / `--user-bubble`；
  选择器限定 `[data-theme='light']`，**暗色主题不受配色影响**（暗色下下拉被禁用）；
- 状态：`localStorage('esp32-chat-palette')` 持久化，默认 `blue`；
  `applyPalette()` 设置 `html[data-palette]` 并按主题禁用/启用下拉。

验证（headless）：
- 设置顺序 主题 → 配色 → 后端；
- 蓝 `--accent #2563eb`/气泡 `#dbeafe`、绿 `#16a34a`/`#dcfce7`、紫 `#7c3aed`/`#ede9fe`、
  橙 `#ea580c`/`#ffedd5`、青 `#0d9488`/`#ccfbf1`，发送按钮与用户气泡同步变色；
- 暗色下配色下拉 `disabled`、`--accent` 保持 `#3b82f6`；
- 切回浅色+绿后刷新，配色持久化保持。
