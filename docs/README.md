# 文档索引（llm-client）

ESP32 局域网大模型客户端项目的全部文档。**新文档按主题进子目录**，一份任务一个文件，
命名用「主题-YYYY-MM-DD」；图类产物（源脚本 + svg + png + 演示页）放同一目录。

## 目录

```
docs/
├── 内存/                      内存相关：实测、瘦身、独立风险审查
│   └── 内存占用图/            内存与存储占用图（生成脚本 + 产物 + 演示页 + 核查报告）
├── 数据流/                    Graphviz 数据流图（端到端 / 一次请求的内存生命周期）
├── 开发/                      代码结构与重构记录
└── README.md                  本索引

tools/render-graphviz.sh       渲染 .dot → svg/png（默认扫 docs/，可传目录）
tools/web-test/                前端 headless 回归测试（puppeteer-core + 本机 Chromium，实机访问板子）
```
